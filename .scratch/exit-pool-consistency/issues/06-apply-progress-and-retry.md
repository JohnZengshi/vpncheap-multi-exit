# 06: 呈现配置生效阶段与失败重试

**What to build:** 用户应用配置后可以区分保存、出口调整和代理池同步；部分失败有准确结果和可用重试。贯通配置提交、Broker 执行、同步状态及桌面和移动端界面。

**Blocked by:** 03 阻止取消仍有绑定的出口；05 明确历史池保留、迁移与清理。

**Status:** ready-for-agent

- [ ] 状态能够关联本次配置，明确显示配置已保存、出口调整中、出口调整失败、同步中及最终结果，不把保存成功等同于全部完成。
- [ ] 出口阶段失败指出失败出口和原因；绑定保护拒绝执行时展示未完成，不宣称出口组合已全部生效。
- [ ] 出口生效而同步失败时显示“出口已生效，代理池同步失败”，保留运行出口，提供具体原因和手动重试，并继续后台重试。
- [ ] 重试重新核验当前配置与归属；手动与后台同步共享执行约束，不造成重复建池或并发旧计划变更。
- [ ] 新配置提交后，旧同步完成或旧失败结果不能覆盖新配置状态；Broker 重启、页面刷新及处理中断后仍能展示可确认的阶段。
- [ ] 重试成功后清除当前已解决的失败状态，但保留必要审计和历史池保留说明；不通过自动回滚出口组合掩盖同步失败。
- [ ] 桌面与移动端可完成选择、核对、应用及重试，禁用原因可见，延续现有视觉风格，无新增页面脚本错误。
- [ ] 隔离集成测试通过真实 Dashboard API 驱动配置与同步，验证部分成功、失败恢复、连续提交、过期结果和重复重试；浏览器验证完整用户流程。
- [ ] 汇总运行相关候选、保护、同步与兼容回归；不新增固定公网 IP 状态、手动换节点或未绑定 Provider 自动分配。

**规格覆盖:** 用户故事 24 至 29；隔离验收 11、12，以及前序任务的组合流程。
